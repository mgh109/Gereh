# اطلاعات تماس فروشگاه

- مدیریت: `/admin/settings/contact`، منوی «اطلاعات تماس».
- صفحه عمومی: `/contact`؛ در منوی دسکتاپ و موبایل و فوتر در دسترس است.
- API خواندنی: `GET /api/v1/contact` با همان داده‌های نمایش داده‌شده در سایت.
- تلفن، ایمیل، آدرس و کدپستی از یک منبع مشترک خوانده می‌شوند. شماره تلفن و ایمیل قابل کلیک هستند.

## نصب روی هاست

برای هاست بدون ترمینال، فایل `database/updates/2026-11-16-contact-settings.sql` را در phpMyAdmin دیتابیس فعلی Import کنید. این اسکریپت تنظیمات موجود را بازنویسی نمی‌کند.

در محیط دارای ترمینال: `php spark migrate --all`.

قبل از نصب جدول، اطلاعات تصویر به‌عنوان مقدار اولیه نمایش داده می‌شود؛ ذخیره تنظیمات نیازمند نصب جدول است. ایمیل خوانده‌شده از تصویر `h3ein157@gmail.com` است؛ پیش از انتشار با صاحب فروشگاه تطبیق داده شود.
