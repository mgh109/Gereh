# انتخاب استان و شهر در سفارش

داده‌های تقسیمات کشوری ۱۴۰۴ از https://github.com/Hameds/IranCountryDivisions در کامیت `37c01f5e776bdd330fbb9d196cff8bf6ceadcb25` با مجوز MIT گرفته شده‌اند. فایل مجوز در `docs/licenses/iran-locations-MIT.txt` نگهداری می‌شود.

۳۱ استان و 1478 نام شهر یکتا در استان مربوط استفاده می‌شود. مناطق شهری و روستاها به‌عنوان شهر تکراری افزوده نشده‌اند. داده‌ها محلی‌اند و صفحه سفارش به سرویس خارجی وابسته نیست.

شهر با تغییر استان پاک می‌شود؛ انتخاب شهر تا تعیین استان غیرفعال است. API ثبت سفارش نیز ارتباط شهر با استان را بررسی می‌کند. API خواندنی `/api/v1/locations` همین فهرست را برمی‌گرداند.
