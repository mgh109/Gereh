# اتصال ملی پیامک به فروشگاه گره

## تنظیم اطلاعات محرمانه

در فایل `.env` خصوصی سرور، و **نه داخل GitHub**، این مقادیر را تنظیم کنید:

```dotenv
GEREH_MELIPAYAMAK_USERNAME = your_account_username
GEREH_MELIPAYAMAK_PASSWORD = your_private_api_password
GEREH_OTP_HASH_SECRET = private_random_string_at_least_32_chars
```

پس از اجرای Migrationها (`php spark migrate --all`) به **پنل ادمین ← تنظیمات پیامک** در `/admin/settings/sms` بروید:

1. سرویس‌دهنده «ملی پیامک (پترن خدماتی)» را انتخاب کنید.
2. در پنل ملی پیامک یک الگوی خدماتی دارای فقط یک متغیر کد شش‌رقمی OTP ایجاد کنید؛ پس از تأیید آن توسط ملی پیامک، **شناسه الگو (Body ID)** را در گره ثبت کنید.
3. «فعال‌سازی ارسال پیامک ورود» را انتخاب و ذخیره کنید.
4. دکمه «بررسی اتصال و اعتبار پنل» را بزنید. این دکمه به وب‌سرویس GetCredit متصل می‌شود و **پیامک واقعی ارسال نمی‌کند**. بررسی مبلغ اعتبار، موفقیت ارسال پترن یا تحویل به کاربر را اثبات نمی‌کند.
5. برای آزمایش نهایی، ورود با موبایل واقعی را در محیط Staging بررسی کنید.

## مسیرهای سرویس

پیاده‌سازی از REST قدیمی رسمی ملی پیامک، با اتصال HTTPS و تأیید TLS استفاده می‌کند:

- الگوی خدماتی: `POST https://rest.payamak-panel.com/api/SendSMS/BaseServiceNumber`
- بررسی اتصال/اعتبار: `POST https://rest.payamak-panel.com/api/SendSMS/GetCredit`

درخواست الگو شامل `username`, `password`, `text` (فقط کد یکبارمصرف)، `to`, `bodyId` است. پاسخ با `RetStatus=1` و شناسه رسید عددی مثبت پذیرفته می‌شود. **پذیرش توسط API معادل تحویل روی سیم‌کارت نیست.**

با توجه به اینکه ملی پیامک APIهای جدید مبتنی بر API Key نیز ارائه می‌دهد، این اتصال برای حساب‌هایی طراحی شده که سرویس REST نام کاربری/رمز عبور دارند. اگر پنل شما فقط API Key ارائه می‌کند، باید آداپتر مناسب آن API به‌جای واردکردن API Key در فیلد رمز متصل شود.

## سیاست امنیتی

- هیچ رمز حساب پیامکی در دیتابیس `sms_settings` ذخیره نمی‌شود؛ این جدول فقط وضعیت فعال‌سازی، سرویس‌دهنده و شناسه الگو را نگه می‌دارد.
- مدیریت تنظیمات و آزمایش اتصال تنها پس از ورود ادمین و با CSRF ممکن است.
- اتصال ملی پیامک پیش‌فرض **غیرفعال** است؛ بدون اطلاعات معتبر هیچ کد ساختگی/ارسال موفق گزارش نمی‌شود.
- OTP شش‌رقمی با مدت انقضا، محدودیت درخواست و تعداد تلاش در `CustomerAuthService` مدیریت می‌شود.
- پیامک‌های تبلیغاتی، ارسال دسته‌جمعی و تغییر الگو از داخل گره فعال نشده‌اند.
- برای فعال‌سازی Production باید تحویل واقعی پیامک، خطای اعتبار یا محدودیت پنل، و کد رد الگو تست شود.
